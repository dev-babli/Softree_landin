# External Integrations

## AI & Machine Learning
- **OpenAI**: Integrated via `openai` package for generative AI solutions.
- **Anthropic AI**: Integrated via `@anthropic-ai/sdk`.
- **Groq**: Fast inference engines and API via `groq-sdk`.

## Financial & Payments
- **Stripe**: Payment processing library (`stripe` sdk).

## Authentication & Identity
- **better-auth**: Core user authorization and identity management system.

## Database
- SQLite/Turso integration using `@libsql/client` combined with Drizzle ORM.

## Third party libraries & SDKs
- `axios` for standard REST request mapping
- `react-google-recaptcha` for bot/spam prevention forms
- Maps and visualization integration: `react-globe.gl` and `dotted-map`
