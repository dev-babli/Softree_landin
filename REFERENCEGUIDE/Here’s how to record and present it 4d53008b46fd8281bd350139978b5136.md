# Here’s how to record and present it

It’s a **step-by-step** guide to get crisp clips for your portfolio and a clean package for developers/clients.

---

## 0) What you’ll need

- **Figma** (prototype ready)
- **Recorder:**
    - **OBS Studio** (best quality, high-end PCs) or
    - **Outplayed** (super simple, great on low-end PCs, I was using this one when I had shitty laptop😶‍🌫️) or
    - **QuickTime** (Mac, basic)
- **Editor:** **CapCut** (desktop) to trim, crop, and export

---

## A) Workflow: Figma → Screen Record → CapCut → Export

### 1) Prep your prototype

1. Open your file → **Present** mode.
2. Set **100% zoom** (avoid fractional zoom; keeps text crisp).
3. Close heavy apps/tabs; switch to **Performance** mode if you have it.
4. Put a neutral desktop background behind the window (helps cropping).
5. Decide the **exact interaction** to record (10–20s max).

### 2) Record the animation

**A. OBS (high-end PCs)**

1. **Canvas:** 1920×1080 (or 1080×1920 for vertical).
2. **FPS:** 60. **Output:** MP4 (H.264), bitrate 12–20 Mbps.
3. Add **Display Capture** (or Window Capture), crop edges if needed.
4. In OBS: Settings → Cursor → **Hide cursor** (unless you need clicks).
5. Hit **Start Recording**, perform the interaction once or twice, **Stop**.

**B. Outplayed (low-end PCs)**

1. Install → choose **Screen** capture.
2. Set **60 fps** and 1080p (or 720p if your machine struggles).
3. Start capture, play the interaction, stop.
    
    *(Outplayed drops fewer frames on modest hardware.)*
    

> Tip: If Figma preview stutters, reduce your monitor resolution or minimize other windows. Stutter in the preview = stutter in the recording.
> 

### 3) Edit & crop in CapCut

1. Import your recording.
2. **Trim** dead time (keep 10–20s).
3. **Crop** tightly around the component/section (use Transform → Crop).
4. **Make it loopable:** start and end on the same state. If needed, duplicate the first 0.3s at the end and cut precisely on a still frame.
5. Optional: add a tiny corner label (e.g., “Hero Entrance”, “Toggle”). Keep typography small and neutral.

### 4) Export settings (choose by channel)

- **Instagram Reels / TikTok (vertical):** 1080×1920, **60 fps**, H.264, high quality.
- **Portfolio / YouTube (landscape):** 1920×1080, **60 fps**, H.264, high quality.
- **Dribbble/Behance:** 1600–1920 width, **60 fps**.
- File name: `project_motion_hero_v1.mp4` (use clear names; you’ll reuse these).

---

This is how you record your prototypes and this recording will be used on your portfolio or present it to the client or when showing the animation to developer.
