## Research Context

### Patterns to Follow

- Reference `src/components/sections/navigation.tsx` for the general navbar component structure used in SOFTREE. Do NOT import from it — build a standalone fizens navbar.
- The fizens navbar uses `position: sticky; top: 0; z-index: 50` with a `backdrop-filter: blur` + white background that appears on scroll.

### Recommended Approach

- Use `useState` + `useEffect` with a scroll event listener to toggle the scrolled background state.
- Mobile hamburger: use `useState` for open/close toggle. Overlay nav covers full viewport height.
- Use `"use client"` since this component uses scroll events and state.

## Implementation Guidance

### Scroll detection

```tsx
'use client'
const [scrolled, setScrolled] = useState(false)
useEffect(() => {
  const handler = () => setScrolled(window.scrollY > 10)
  window.addEventListener('scroll', handler, { passive: true })
  return () => window.removeEventListener('scroll', handler)
}, [])
```

### Styling approach

Use inline styles or Tailwind classes. Import `./fizens.css` for CSS variables. Example:

```tsx
<nav style={{
  position: 'sticky', top: 0, zIndex: 50,
  background: scrolled ? 'white' : 'transparent',
  transition: 'background 0.3s ease, box-shadow 0.3s ease',
  boxShadow: scrolled ? '0 1px 8px rgba(0,0,0,0.08)' : 'none'
}}>
```

### Edge Cases

- Hamburger menu should close when a nav link is clicked.
- Prevent body scroll when mobile overlay is open: `document.body.style.overflow = 'hidden'` on open, restore on close.
