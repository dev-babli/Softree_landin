### Recommended Approach

- **Count-up animation:** Use `IntersectionObserver` to detect when the stats section enters viewport, then run a `requestAnimationFrame` loop that increments the displayed number from 0 to target over ~1.5 seconds with an ease-out curve.
- **Statistics background:** Dark section. Use `background: linear-gradient(135deg, #0a0a0a 0%, #0040c1 100%)` or `background: #0a0a0a` with text in white and blue accents.
- **How It Works:** 3 steps in a horizontal row at desktop. Each step: large number (bold, `--fizens-blue-primary`), icon, title, description. Vertical at mobile.
- Mark component `"use client"` since it uses IntersectionObserver and state.

## Implementation Guidance

### Count-up hook

```tsx
'use client'
function useCountUp(target: number, duration = 1500) {
  const [count, setCount] = useState(0)
  const [started, setStarted] = useState(false)
  const ref = useRef<HTMLDivElement>(null)

  useEffect(() => {
    const observer = new IntersectionObserver(
      ([entry]) => { if (entry.isIntersecting && !started) setStarted(true) },
      { threshold: 0.3 }
    )
    if (ref.current) observer.observe(ref.current)
    return () => observer.disconnect()
  }, [started])

  useEffect(() => {
    if (!started) return
    let start: number | null = null
    const step = (ts: number) => {
      if (!start) start = ts
      const progress = Math.min((ts - start) / duration, 1)
      setCount(Math.floor(progress * target))
      if (progress < 1) requestAnimationFrame(step)
    }
    requestAnimationFrame(step)
  }, [started, target, duration])

  return { count, ref }
}
```

For "50K+", "99.9%", "$2B+", "4.9★" — animate the numeric portion (50000, 99, 2, 4.9) and append the suffix as a static string.
